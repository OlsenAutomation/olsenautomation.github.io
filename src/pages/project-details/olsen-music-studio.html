One system. Separate learning paths.

Brian describes a working local learning application with independent Clarinet and Guitar curriculum packs. Clarinet coordinates lessons while preserving separate observations; Guitar supports self-directed practice with explicit evidence sources and stop conditions.

The owner-reported system includes a lesson compiler, review lifecycle and backups. Progress for one instrument or learner must not advance another. This public summary contains no learner records or private curriculum files.

Evidence before advancement.

Self-observation is labeled as self-observation. A generated lesson does not become accepted merely because software produced it, and technique-sensitive advancement can require qualified outside evidence. No automatic listening or technique-analysis capability is claimed here.
