Getting through the front door.

Cloudflare is simply the private entrance. You do not need to create a Cloudflare account or install anything.

Request access below.

Enter the email address you want to use. Your mail app will prepare a message to Brian so he can add that exact address.

Access is not automatic. Wait for Brian to confirm that your address has been added.

Open the private game site.

Visit play.olsenfamilygames.com. Cloudflare will ask for your approved email address before it shows the game.

If you saved the page before approval, refresh it after Brian confirms access.

Ask Cloudflare for a code.

Enter the approved email exactly, choose to send a one-time PIN, then check that inbox for the sign-in message.

Check Spam or Junk if the code does not appear. Use the newest code if you requested more than one.

Enter the code and play.

After Cloudflare accepts the code, Family Card Chaos opens. Your approved session can remain signed in for a while, so you may not see the code screen every time.

Cloudflare protects the doorway; the six-digit room code puts you at the correct game table.

Once the game opens.

Everyone joins from their own screen. The host controls the room and chooses which card packs are in play.

Choose Host or Join.

One person chooses Host a game. Everyone else chooses Join a game.

Unless Brian says otherwise, join the room instead of starting a second one.

Pick your family profile.

Choose your name, enter a playful game-night name, and optionally add a headshot from your device.

Photos are temporary and are not stored in GitHub or used for Cloudflare access.

Enter the room code.

Type the six-digit code shown on the host’s lobby screen. The host can wait for everyone before starting.

Room codes change between games. Ask the current host for the newest one.

Play your cards.

Submit from your private hand, watch the answers reveal, and let the rotating judge choose the winner.

The host decides whether the selected packs are family-safe or adult. Check before younger players join.

Ask to be added.

If something gets stuck.

Most problems come from using a different email, an older code, or the host computer being offline.

“Email not allowed”

Make sure you used the exact address Brian approved. If it still fails, send a new access request below.

No code arrived

Check Spam or Junk, wait a minute, and request one new code. Enter the newest message you receive.

“Can’t reach the host”

The Mac mini or game server may be offline. Text Brian; refreshing repeatedly will not restart the host.
