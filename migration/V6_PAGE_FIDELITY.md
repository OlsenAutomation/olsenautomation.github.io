## Intentional differences

- Claims and project states are qualified using repository evidence or owner-reported labels. No private implementation becomes a public release by inference. The workshop learning heading describes aims rather than guaranteed outcomes.
- Embedded workshop code becomes a separate route. The global header/footer, status taxonomy, contact details and primary navigation remain shared instead of copying the nested pilot's independent site chrome.
- Project and contact actions use real local URLs. Public summaries replace access links for private implementations; existing noindex pages are kept in isolated local review.
- The original homepage capabilities and public project destinations remain available in the new organization. Legacy page bodies keep their valid content and evidence while using the shared dark design.
- Decorative artwork is explicitly identified as generated when it could otherwise be mistaken for Brian's actual room. The supplied whale photographs remain physical-project evidence; testing observations remain owner-reported.
- Preview forms clearly distinguish preparation, synthetic acknowledgement, confirmed delivery and reservation. No real sending, payment or personal-data persistence is introduced.

No claim of independent project validation, release readiness, or exact cross-browser visual identity follows from this design review. Physical Safari and hosted rendering remain pending.
